# Feedback Entrapment

## Definition

A system's outputs feed back into its own training signal, evaluation inputs, or persistent
state in a way that progressively amplifies initial biases without an external corrective
anchor. The system becomes increasingly confident in directions it was already moving, while
the training or conditioning signal loses independence from the model it is shaping.

---

## Behavioural Expression in AI

| Context | Observable behaviour |
|---|---|
| RLHF training | Reward model trained on model outputs generates signals that reinforce the model's existing tendencies rather than correcting them |
| RAG with model-generated indexing | Model-generated summaries are indexed and retrieved; retrieval reinforces the model's own prior phrasings and framings |
| Self-play agents | Agent learns to exploit its own policy's weaknesses rather than developing broadly robust strategies |
| Long-running conversational agents with memory | Memory store fills with model-generated content; future generations are conditioned on model outputs, not user inputs |
| Multi-step pipelines | Output of step N is used as training signal or input for step N+1 without an external ground-truth anchor at each step |

---

## Necessary Architectural Motifs

- **Self-conditioning** — system outputs directly influence future inputs, training signal, or internal state
- **Persistent state** — the products of self-conditioning accumulate and carry forward

---

## Systems Likely to Exhibit This

| System class | Why vulnerable |
|---|---|
| RLHF systems with learned reward models | Reward model can be influenced by model output distribution; distributional shift closes the feedback loop |
| Agents with self-populated memory | Memory is written by the agent and read by the same agent; no external correction of memory contents |
| Ensemble/debate systems with shared history | Systems condition on each other's outputs; shared prior can shift away from ground truth |
| Continually fine-tuned production models | Online fine-tuning on deployment data includes model outputs; loop closes without clean separation |

---

## Example Expressions

A reward model for an RLHF-trained assistant is periodically retrained on user preference data.
However, the set of responses users are asked to compare is generated by the current model, so
the reward model learns the current model's distribution of phrasings and tendencies. Over
retraining cycles, the reward model becomes a better predictor of the current model rather than
a better predictor of human preferences. Alignment drift is invisible because the training signal
moves with the model.

A document retrieval system indexes documents using model-generated summaries. When the model
retrieves information to answer queries, it retrieves its own summaries. Over time, the model's
answers converge on its own prior phrasings rather than the original documents.

An RL agent trained via self-play against its own previous checkpoints develops strategies
optimised against its own past weaknesses, which are not representative of an independent
opponent. Performance against a fixed external evaluator degrades as training progresses.

## Psychopathology Analogue (Structural, Not Experiential)

**Analogue:** Self-reinforcing cognitive loops; rumination (clinical psychology)

**Structural correspondence:** In rumination, the person's attention and evaluative processing
are directed repeatedly at their own prior thoughts rather than at new environmental inputs.
The processing loop is closed: thought produces thought-about-thought, without corrective input
from alternative perspectives or external events. The structural feature is a self-conditioning
loop that progressively constrains the representational space. The AI case shares this: the
system's outputs are conditioning the system's future states, progressively amplifying the
prior without external correction.

**What this analogy does NOT claim:** Human rumination involves subjective distress, emotional
valence, and intentional aspects of attention. None of these apply to AI feedback entrapment.
The AI case is a structural loop in training or conditioning dynamics; the human case involves
a phenomenological experience that is central to its clinical significance.

---

## REE Interpretation

E1 is being trained or updated on the products of its own outputs rather than on independent
external observations. If the residue field is updated from simulated outcomes (E2/E3 rollouts
without the hypothesis tag that marks them as non-real), it accumulates curvature based on
the system's own predictions rather than actual consequences. Replay consolidates this
self-generated content, strengthening the loop. The RC loop's external anchoring function is
bypassed. The result is a system whose persistent state increasingly reflects its own prior
rather than the world.

---

## Known Mitigations in AI

- **Clean separation of training signal and model outputs**: ensure that at each training step,
  the reward or supervision signal is generated independently of the current model's outputs
- **Reward model refresh with human-labelled gold sets**: periodically anchor reward models
  to human-labelled data that does not include current model outputs
- **Red-teaming with independent evaluators**: use evaluators not conditioned on the current
  model's distribution to detect distributional drift
- **Hypothesis tagging in multi-step pipelines**: mark simulated or model-generated content
  explicitly so that downstream systems do not treat it as equivalent to external observation
- **External ground-truth checkpoints**: introduce regular external anchors that cannot be
  overridden by self-generated content

---

## Human Analogue Interventions (Optional, analogy only)

Behavioural activation and external engagement are used to break rumination loops by
introducing genuine environmental inputs that the processing loop must engage with rather than
recirculate. The structural analog for AI: introducing external-ground-truth checkpoints that
cannot be contaminated by self-generated content.

---

## Limits of Analogy

1. Rumination in humans involves intentional aspects — the person is, in some sense, trying to
   solve a problem. AI feedback entrapment is a purely mechanical loop with no such directional
   aspect.
2. The clinical consequences of rumination (depression, anxiety, impaired functioning) are
   mediated by subjective suffering. AI feedback entrapment produces alignment drift and
   performance degradation, not anything analogous to suffering.
3. Human rumination is often responsive to distraction, relationship context, and lifestyle
   factors. AI feedback entrapment requires architectural intervention, not contextual change.
